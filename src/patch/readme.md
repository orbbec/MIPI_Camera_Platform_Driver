## Patch Installation Instructions

This repository contains driver files for Orbbec GMSL interface cameras. It is intended to help developers and customers integrate Orbbec GMSL cameras into their platforms.

Please select the appropriate patch according to your platform and JetPack version. If there is no patch for your exact JetPack version, you may refer to the patch for a nearby JetPack version.

For example, if you are using the JetPack 6.1 source code, you can refer to the JetPack 6.0 patch to resolve some conflicts.

For detailed installation steps, please refer to the README file in the corresponding directory.
