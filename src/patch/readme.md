## Patch Installation Instructions
This repository contains driver files for Orbbec GMSL interface cameras, designed to facilitate the integration of GMSL interface cameras for developers and customers. Please select the corresponding patch based on your platform. For example, if you use the source code of JetPack 6.1, you can refer to the Patch of JetPack 6.0 to resolve partial conflicts. For detailed installation steps, please refer to the README file in the corresponding directory.
